So geht's los

  1. Die DMG öffnen und „StageCase“ in den Ordner Programme ziehen, dann starten.
  2. Der Einrichtungs-Assistent führt durch alles Weitere und installiert das Remote Script für Live.
  3. Wichtig, in Live: Einstellungen → Link, Tempo & MIDI → bei einer freien Bedienoberfläche „Stagecase“ wählen, Eingang und Ausgang ebenfalls „Stagecase“. Danach Live einmal beenden und neu starten.
  4. Tablet oder Handy: die Adresse öffnen, die StageCase anzeigt – beide Geräte im selben WLAN.

Getting started

  1. Open the DMG, drag “StageCase” into Applications and start it.
  2. The setup assistant guides you through the rest and installs the Remote Script for Live.
  3. Important, in Live: Settings → Link, Tempo & MIDI → pick “Stagecase” as a free control surface, with input and output “Stagecase” too. Then quit and restart Live once.
  4. Tablet or phone: open the address StageCase shows – both devices on the same Wi-Fi.

Licence key

Enter the key in StageCase under Extras → Licence. No key yet? Write to info@casework-software.com. Without a key StageCase keeps running for free with one looper. The app tells you about new versions itself.

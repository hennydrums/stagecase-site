Getting started

  1. Open the DMG, drag “StageCase” into Applications and start it. Already running StageCase? Skip this step.
  2. Enter the key from the e-mail under Extras → Licence. It works on 2 Macs.
  3. The setup assistant guides you through the rest and installs the Remote Script for Live.
  4. Important, in Live: Settings → Link, Tempo & MIDI → pick “Stagecase” as a free control surface, with input and output “Stagecase” too. Then quit and restart Live once.
